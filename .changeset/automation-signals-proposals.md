Automations can now see your work and put it in front of you. A new Morning triage automation pulls the issues assigned to you and the pull requests waiting on your review, ranks them by what is blocking other people, and proposes what to do about each one. Proposals wait for you: start one and Argus opens a worktree with an agent already briefed on it, or dismiss it with a reason. If GitHub is not signed in the run still finishes and simply reports that it found nothing.
