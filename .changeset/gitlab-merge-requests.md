Projects hosted on GitLab, including self-hosted instances, now get the same merge request support as GitHub pull requests: the state icon on each session, the Pull Requests list and detail, opening a merge request, watched pipelines that wake the agent when a job fails, and GitLab issues as an automation source. It goes through the GitLab CLI (`glab`), so sign in with `glab auth login`.
