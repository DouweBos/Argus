Automations can now start from events: a new issue or pull request, an assignment, a review request, a red CI run on your pull request, or a mention on GitHub, GitLab or Linear, or a signed webhook from any other service. The run gets the event itself, such as the failing log or the comment, and three new templates use these triggers: Fix my red CI, Review requested and Triage new issues.
