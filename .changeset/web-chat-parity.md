The web client catches up on chat: start an agent from any session in the current checkout, a new worktree or an existing branch, with its model, mode, effort, images and linked projects. Each turn's work folds into a "Worked for…" line, messages can be copied, edited or forked, agents pinned, and a session's recent chats searched, resumed or deleted. Agents show their MCP servers, a chat stuck on a spent limit offers your other accounts, and project and session lists update as they change on your computer.
